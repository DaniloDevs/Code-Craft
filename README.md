## 🎯 Sobre o Projeto

O **Code-Craft** é um sistema de indicação e ranking desenvolvido com foco em performance, escalabilidade e manutenibilidade. O projeto implementa uma arquitetura limpa com separação clara de responsabilidades, utilizando tecnologias modernas como Fastify, Prisma, Redis e TypeScript.

## ✨ Funcionalidades

### 🔐 Sistema de Inscrição
- Inscrição em eventos com nome e email
- Sistema de referência com tracking de convites
- Validação de dados únicos e formato
- Geração automática de IDs únicos

### 🏆 Sistema de Ranking
- Ranking baseado em número de indicações
- Posicionamento em tempo real
- Cache otimizado para consultas frequentes
- Histórico de acessos por convite


## 🛠️ Tecnologias

### **Backend**
- **Node.js** - Runtime JavaScript
- **TypeScript** - Linguagem principal
- **Fastify** - Framework web de alta performance
- **Zod** - Validação de schemas

### **Banco de Dados**
- **PostgreSQL** - Banco principal
- **Prisma** - ORM type-safe
- **Redis** - Cache e rankings

## 📋 Pré-requisitos

- **Node.js** 18+ 
- **npm** ou **pnpm**
- **Docker** e **Docker Compose**
- **PostgreSQL** 14+
- **Redis** 7.0+
